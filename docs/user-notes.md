Need a simple rules-based Leave Management System application, where an employee can apply for leaves and a manager can approve it.
* Every employee starts with a baseline of 15 days of annual leave.
* The system must allow the employee to know their leave balance, and submit a request.
* To submit a request, the system must allow the employee to select a start date and an end date.
* Leave requests cannot exceed the employee's remaining balance.
* Leave requests must be approved by the Manager.

Tech Stack
Frontend:
* React/JS
* Tooling: Vite

Backend:
* ASP.NET Core Minimal API
* TargetFramwork is .net10.0
* Test Framework: xUnit
